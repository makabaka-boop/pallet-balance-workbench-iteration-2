# 异形托盘叉车起运 · 稳定性工作台

叉车起运异形托盘前，判断**货物合成重心是否落在支撑区域内并留有规定安全余量**的纯前端（不联网）工作台。TypeScript + React + Vite 实现，Docker Compose 运行，Vitest 核对几何边界。

## 功能

- **整批导入校验**
  - 支撑多边形：按**逆时针**顺序给出的**严格凸**多边形（`[x,y]` 或 `{x,y}`，坐标绝对值 ≤ 10⁶ 的有限数）。
  - 货物：1–200 件，每件含唯一 `id`、**正数** `weight`、有限 `center`，以及**可选的正数 `weightMin` / `weightMax`**（散装货称重误差范围；省略任一端即沿用登记重量，区间必须包含 `weight`）。
  - `margin`：非负数，缺省 0。
  - 重复顶点、共线/退化、非凸（含五角星类自交）、顺时针、非法重量、**非法重量范围**（零/负/非有限、`min > max`、登记重量落在范围外）、件数越界、坐标越界、**任何未知字段**（顶层 / 货物 / 点）一律**整批拒绝并保留当前工作区**，错误一次性列出。
- **实时编辑**：每件货物的重量、可选重量上下界与中心可直接改，margin 可改；输入即重算，非法编辑（含非法范围）立即撤销当前结论。
- **稳定性判断（同一份计算结果驱动图与数）**
  - 按重量实时计算**标称**合成重心（未舍入；极端重量自动按最大重量缩放，合计重量溢出时重心仍可靠）。
  - 计算重心到每条支撑边的**有符号距离**（逆时针多边形内部为正），取最小值。
  - `minDistance >= margin` 显示 **STABLE**；否则显示 **UNSTABLE**，并给出最危险边、实际余量、短缺量（重心越出边时距离为负）。
  - 边界比较直接使用未舍入浮点值（margin=0 时恰在边界上算稳定，保持兼容）；面板展示保留 6 位小数，悬停可见原值。
  - **极小非零量不抹零**：余量/短缺在 6 位小数下会被舍入成 0 时自动改用科学计数法；需要互相比较的指标（实际余量 vs 要求余量、富余/短缺）成对格式化，两个不同原值不会显示成同一个数，杜绝“实际余量 0 小于要求 0”。
- **鲁棒放行结论（散装货称重误差）**
  - 每件货物可给允许重量闭区间 `[weightMin, weightMax]`（省略即确定重量，旧 JSON 完全兼容）；放行前必须证明：**支撑多边形的每一条边，在所有允许重量组合下**重心距离都 `>= margin`——检查标称值或抽样均不算数。
  - 距离为重量的线性分式（`Σwᵢdᵢ/Σwᵢ`），其水平集是盒域上的线性阈值，故**极值必在区间端点组合处取得**；实现按各件到该边距离排序后只枚举 n+1 个候选切点精确求全局最小（件数 ≤ 200），全部运算按最大重量归一化，合计重量溢出时鲁棒结论仍可靠。
  - 任一边最差距离 `< margin` 即**鲁棒不放行**，返回**可复算见证**：一组每件均取区间端点的极端重量、该组合下的合成重心、**首先失守的边**（平局取序号最小）及其距离/短缺；面板列出见证重量表，SVG 用**橙色三角 + 橙色粗边**标注，与标称重心（青色十字）、标称最危险边（红色粗边）明确区分。
  - 边界相等（最差距离恰好等于 margin）算满足。总放行 `releasable` 必须同时满足标称稳定、无不可表达量告警、鲁棒稳定；**数值无法可靠裁决或存在失守组合时绝不显示可放行**。无重量范围时鲁棒结论与标称结论逐条相等。
- **几何区域与数值判定一致**
  - 安全区优先用相邻平移边交点直接构造（单步误差不累积）；裁剪容差只取坐标尺度的舍入噪声，**不随 margin 放大**——边长 100、margin=1e-12 时安全区真正向内平移约 1e-12，绝不贴回原支承边冒充合格。
  - margin 小到低于当前坐标尺度的浮点分辨极限（约 8·ε·M）时，安全区不绘制（而不是画一个与原边无异的假区域），图形与面板同时告警。
- **无法可靠表达的量必须显式反馈，且不得放行**
  - 两件有限合法大重量之和超出 double 范围时，**合计重量显示为“缺失（溢出，不可审核）”**（`totalWeight: null`）；重心几何结论照常给出，但状态为琥珀色**暂缓放行**（`releasable=false`，伴随告警），不把未知合计量伪装成可审核的正常载荷。
  - 余量低于图形分辨极限同理：数值判定照给，但带告警、不可放行。
- **SVG 俯视图**：支撑区、margin 内缩安全区（半平面裁剪）、货物（半径 ∝ √登记重量）、标称合成重心、标称最危险边（红色粗边）及重心到该边的实际余量垂线，以及鲁棒失败时的失守边（橙色粗边）与失败见证重心（橙色三角），全部取自同一个 `StabilityResult`（含 `robust` 字段）。
- **编辑即撤销旧结论**：任何非法输入（含非法重量范围）都会让数值面板与图形同时进入「结论已撤销 / 无结论」状态，不会残留过期的 STABLE/UNSTABLE 或鲁棒结论。

## 本地运行

```bash
npm install
npm run dev       # http://localhost:5173，纯前端、无后端、无外部网络请求
npm run test      # Vitest（81 个几何/校验/鲁棒/验收用例）
npm run build     # 类型检查 + 产物到 dist/
```

## Docker Compose

```bash
docker compose up --build
# 打开 http://localhost:8080
```

镜像为多阶段构建：构建阶段跑 Vitest 与 `vite build`，运行阶段仅用 Nginx 托管静态文件。

## 导入格式

```json
{
  "polygon": [[0,0],[4200,0],[4200,1400],[3200,2200],[900,2200],[0,1500]],
  "margin": 150,
  "items": [
    { "id": "A-箱", "weight": 120, "weightMin": 108, "weightMax": 132, "center": [1200, 800] },
    { "id": "B-桶", "weight": 210, "weightMin": 189, "weightMax": 231, "center": [2400, 1100] }
  ]
}
```

`weightMin` / `weightMax` 均可选：只给一边即为单边范围，都省略即为旧格式的确定重量；登记重量 `weight` 必须始终落在范围内。

页面「载入示例」可直接填入一份可用数据。

## 关键实现

| 文件 | 内容 |
| --- | --- |
| `src/lib/geometry.ts` | 严格凸/逆时针校验、有符号距离、加权重心（溢出时 totalWeight=null）、分辨极限感知的内缩（直接交点构造 + 半平面裁剪兜底）、`analyzeRobustness`（每边线性分式盒域端点精确极值，非抽样；溢出安全）、`analyzeStability` 单一结果源 |
| `src/lib/parse.ts` | 导入数据严格校验（未知字段、范围、件数、**重量上下界**、整批拒绝） |
| `src/lib/form.ts` | 编辑表单解析（含可选重量范围），非法即撤销结论；`fmt` 不抹零（科学计数法）、`fmtPair` 成对可区分格式化 |
| `src/components/PlanView.tsx` | 与数值面板共用 `StabilityResult` 的 SVG 俯视图；标称重心（青十字）与鲁棒失败见证（橙三角/橙粗边）分绘；按可放行状态着色，不可表达量图面告警 |
| `src/components/ResultPanel.tsx` | STABLE / 暂缓放行 / UNSTABLE、鲁棒可放行/鲁棒不放行、可复算见证重量表、各边标称距离与最差组合距离、溢出缺失反馈 |
| `src/lib/geometry.test.ts` | 凸性/退化/自交、距离符号、加权重心、内缩塌缩、边界稳定性、整批拒绝等用例 |
| `src/lib/acceptance.test.ts` | 极小正余量内缩、边界重心、微小短缺不抹零、大重量溢出、低于分辨极限、导入编辑一致性等验收用例 |
| `src/lib/robust.test.ts` | 鲁棒分析：以**少件货物全部端点组合（2ⁿ）独立枚举为预言机**逐边核对；覆盖边界相等、极端重量溢出、无范围退化、非法范围整批拒绝、非法行内编辑撤销后的图文一致性 |
