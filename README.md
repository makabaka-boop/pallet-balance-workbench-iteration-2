# 异形托盘叉车起运 · 稳定性工作台

叉车起运异形托盘前，判断**货物合成重心是否落在支撑区域内并留有规定安全余量**的纯前端（不联网）工作台。散装货存在称重误差时，还必须证明：**在各件货物实际重量落入登记范围的任意组合下**，重心对支撑多边形的每条边都满足安全余量。TypeScript + React + Vite 实现，Docker Compose 运行，Vitest 核对几何边界与鲁棒证明。

## 功能

- **整批导入校验**
  - 支撑多边形：按**逆时针**顺序给出的**严格凸**多边形（`[x,y]` 或 `{x,y}`，坐标绝对值 ≤ 10⁶ 的有限数）。
  - 货物：1–200 件，每件含唯一 `id`、**正数** `weight`、有限 `center`，以及**可选的正数重量区间** `weightMin` / `weightMax`。
    - 两个端点都省略：沿用确定重量 `weight`（**旧 JSON 完全兼容**）。
    - 只给一端：缺省端沿用 `weight`；给出区间时必须满足 `weightMin ≤ weight ≤ weightMax`。
  - `margin`：非负数，缺省 0。
  - 重复顶点、共线/退化、非凸（含五角星类自交）、顺时针、非法重量、**非法重量区间**、件数越界、坐标越界、**任何未知字段**（顶层 / 货物 / 点）一律**整批拒绝并保留当前工作区**，错误一次性列出。
- **实时编辑**：每件货物的重量、**重量下/上界**与中心可直接改，margin 可改；输入即重算，任何非法编辑（含下界＞上界、标称重量移出区间）立即**撤销当前结论**，图与数同时进入「无结论」状态。
- **两层稳定性结论（同一份分析结果驱动图与数）**
  - **标称结论（保留原口径）**：按登记重量实时计算合成重心（未舍入；极端重量自动按最大重量缩放，合计重量溢出时重心仍可靠）、重心到每条支撑边的有符号距离（逆时针内部为正），`minDistance >= margin` 为标称 STABLE。
  - **鲁棒放行结论（新增）**：每件货物允许重量构成一个重量盒。重心到边的距离是重量的**分式线性函数，其极值必在盒的角点取得**，因此
    - 少件货物（≤ 12 件）**枚举全部 2ⁿ 个端点组合**，对支撑多边形**每条边**逐一证明最坏距离 ≥ margin——是完整证明而非抽样，仅检查标称值同样不被接受；
    - 多件货物改用 Charnes–Cooper 线性化 + 两阶段单纯形精确求解同一分式线性规划，并以启发式角点扫描交叉校验；
    - 不满足时返回一组**可独立复算的极端重量**（全部为区间端点）、**对应重心**、见证合计重量与**首先失守的边**（边序最小的最坏边，平局确定可复现）；
    - 数值无法可靠裁决（交叉校验不过/未收敛）或存在允许组合合计重量溢出 double 时，结论为「无法裁决 / 暂缓放行」，**绝不显示可放行**。
  - 边界比较直接使用未舍入浮点值（最坏距离恰等于 margin 算通过；margin=0 时恰在边界上算稳定，保持兼容）；面板展示保留 6 位小数，悬停可见原值。
  - **极小非零量不抹零**：余量/短缺在 6 位小数下会被舍入成 0 时自动改用科学计数法；需要互相比较的指标成对格式化，两个不同原值不会显示成同一个数。
- **几何区域与数值判定一致**
  - 安全区优先用相邻平移边交点直接构造（单步误差不累积）；裁剪容差只取坐标尺度的舍入噪声，**不随 margin 放大**。
  - margin 小到低于当前坐标尺度的浮点分辨极限（约 8·ε·M）时，安全区不绘制（而不是画一个与原边无异的假区域），图形与面板同时告警。
- **无法可靠表达/裁决的量必须显式反馈，且不得放行**
  - 两件有限合法大重量之和超出 double 范围时，**合计重量显示为“缺失（溢出，不可审核）”**（`totalWeight: null`）；标称重心几何结论照常给出，但 `releasable=false`。
  - 任意允许重量组合（最大总和角点）溢出时附加 `robust-corner-overflow` 告警；区间分析无法收敛/未通过交叉校验时附加 `robust-indeterminate`。
- **SVG 俯视图（与面板共用同一 `StabilityResult`）**：支撑区、margin 内缩安全区（半平面裁剪）、货物（半径 ∝ √标称重量，有区间的货物用虚线圈标示半径上下界）、**标称重心（青色十字）与鲁棒失败见证（红粉五边形，极端组合下的重心）明确区分且同时绘制**、标称最危险边与鲁棒首先失守边、各自的实际余量垂线。放行状态（绿/琥珀/红描边）只取自同一结论。
- **编辑即撤销旧结论**：任何非法输入都会让数值面板与图形同时进入「结论已撤销 / 无结论」状态，不会残留过期的 STABLE/UNSTABLE/鲁棒放行。

## 本地运行

```bash
npm install
npm run dev       # http://localhost:5173，纯前端、无后端、无外部网络请求
npm run test      # Vitest（94 个几何/鲁棒/校验/验收/图文一致性用例）
npm run build     # 类型检查 + 产物到 dist/
```

## Docker Compose

```bash
docker compose up --build
# 打开 http://localhost:8080
```

镜像为多阶段构建：构建阶段跑 Vitest 与 `vite build`，运行阶段仅用 Nginx 托管静态文件。

## 导入格式

```json
{
  "polygon": [[0,0],[4200,0],[4200,1400],[3200,2200],[900,2200],[0,1500]],
  "margin": 150,
  "items": [
    { "id": "A-箱", "weight": 120, "center": [1200, 800] },
    { "id": "B-桶", "weight": 210, "weightMin": 195, "weightMax": 225, "center": [2400, 1100] },
    { "id": "C-架", "weight": 165, "weightMin": 150, "center": [2900, 1650] }
  ]
}
```

- `A-箱` 无区间字段：确定重量 120（旧格式）。
- `B-桶`：实际重量允许 195–225，标称 210。
- `C-架`：只给下界 150，上界缺省即沿用标称重量 165。

页面「载入示例」可直接填入一份含区间的可用数据。

## 关键实现

| 文件 | 内容 |
| --- | --- |
| `src/lib/robust.ts` | 重量区间模型；分式线性最坏距离；少件 **2ⁿ 全角点枚举（= 独立预言机）**；多件 Charnes–Cooper + 两阶段单纯形（平移变量形式，窄区间条件良好）与启发式交叉校验；角点溢出检测；见证重量/重心/首先失守边构造 |
| `src/lib/geometry.ts` | 严格凸/逆时针校验、有符号距离、加权重心（溢出时 totalWeight=null）、分辨极限感知的内缩、`analyzeStability` 单一结果源（标称 + 鲁棒同源） |
| `src/lib/parse.ts` | 导入严格校验（未知字段、范围、`weightMin/weightMax` 合法性与包含关系、件数、整批拒绝） |
| `src/lib/form.ts` | 编辑表单解析（区间字段非法即撤销结论）；`fmt` 不抹零、`fmtPair` 成对可区分格式化 |
| `src/components/PlanView.tsx` | 与面板共用 `StabilityResult` 的 SVG：标称重心（青十字）与失败见证（红粉五边形）区分、区间半径虚线圈、按可放行状态着色 |
| `src/components/ResultPanel.tsx` | 顶层鲁棒徽标（放行/不放行/暂缓）、标称指标、每边“标称/允许组合最坏”距离表、可复算见证明细（极端重量向量+重心+失守边） |
| `src/lib/geometry.test.ts` | 凸性/退化/自交、距离符号、加权重心、内缩塌缩、边界稳定性、整批拒绝等用例 |
| `src/lib/acceptance.test.ts` | 极小正余量内缩、边界重心、微小短缺不抹零、大重量溢出、低于分辨极限、导入编辑一致性等验收用例 |
| `src/lib/robust.test.ts` | **少件全端点组合独立预言机**（逐边核对）、边界相等（含最坏角点恰好压线）、n=13/16/20/200 的 LP 路径、无范围兼容、溢出见证、非法区间整批拒绝、非法编辑后结论撤销等 |
