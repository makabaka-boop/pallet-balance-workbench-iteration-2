# 异形托盘叉车起运 · 稳定性工作台

叉车起运异形托盘前，判断**货物合成重心是否落在支撑区域内并留有规定安全余量**的纯前端（不联网）工作台。TypeScript + React + Vite 实现，Docker Compose 运行，Vitest 核对几何边界。

## 功能

- **整批导入校验**
  - 支撑多边形：按**逆时针**顺序给出的**严格凸**多边形（`[x,y]` 或 `{x,y}`，坐标绝对值 ≤ 10⁶ 的有限数）。
  - 货物：1–200 件，每件含唯一 `id`、**正数** `weight`、有限 `center`。
  - `margin`：非负数，缺省 0。
  - 重复顶点、共线/退化、非凸（含五角星类自交）、顺时针、非法重量、件数越界、坐标越界、**任何未知字段**（顶层 / 货物 / 点）一律**整批拒绝并保留当前工作区**，错误一次性列出。
- **实时编辑**：每件货物的重量与中心可直接改，margin 可改；输入即重算。
- **稳定性判断（同一份计算结果驱动图与数）**
  - 按重量实时计算合成重心（未舍入；极端重量自动按最大重量缩放，合计重量溢出时重心仍可靠）。
  - 计算重心到每条支撑边的**有符号距离**（逆时针多边形内部为正），取最小值。
  - `minDistance >= margin` 显示 **STABLE**；否则显示 **UNSTABLE**，并给出最危险边、实际余量、短缺量（重心越出边时距离为负）。
  - 边界比较直接使用未舍入浮点值（margin=0 时恰在边界上算稳定，保持兼容）；面板展示保留 6 位小数，悬停可见原值。
  - **极小非零量不抹零**：余量/短缺在 6 位小数下会被舍入成 0 时自动改用科学计数法；需要互相比较的指标（实际余量 vs 要求余量、富余/短缺）成对格式化，两个不同原值不会显示成同一个数，杜绝“实际余量 0 小于要求 0”。
- **几何区域与数值判定一致**
  - 安全区优先用相邻平移边交点直接构造（单步误差不累积）；裁剪容差只取坐标尺度的舍入噪声，**不随 margin 放大**——边长 100、margin=1e-12 时安全区真正向内平移约 1e-12，绝不贴回原支承边冒充合格。
  - margin 小到低于当前坐标尺度的浮点分辨极限（约 8·ε·M）时，安全区不绘制（而不是画一个与原边无异的假区域），图形与面板同时告警。
- **无法可靠表达的量必须显式反馈，且不得放行**
  - 两件有限合法大重量之和超出 double 范围时，**合计重量显示为“缺失（溢出，不可审核）”**（`totalWeight: null`）；重心几何结论照常给出，但状态为琥珀色**暂缓放行**（`releasable=false`，伴随告警），不把未知合计量伪装成可审核的正常载荷。
  - 余量低于图形分辨极限同理：数值判定照给，但带告警、不可放行。
- **SVG 俯视图**：支撑区、margin 内缩安全区（半平面裁剪）、货物（半径 ∝ √重量）、合成重心、最危险边（红色粗边）及重心到该边的实际余量垂线，全部取自同一个 `StabilityResult`。
- **编辑即撤销旧结论**：任何非法输入都会让数值面板与图形同时进入「结论已撤销 / 无结论」状态，不会残留过期的 STABLE/UNSTABLE。

## 本地运行

```bash
npm install
npm run dev       # http://localhost:5173，纯前端、无后端、无外部网络请求
npm run test      # Vitest（56 个几何/校验/验收用例）
npm run build     # 类型检查 + 产物到 dist/
```

## Docker Compose

```bash
docker compose up --build
# 打开 http://localhost:8080
```

镜像为多阶段构建：构建阶段跑 Vitest 与 `vite build`，运行阶段仅用 Nginx 托管静态文件。

## 导入格式

```json
{
  "polygon": [[0,0],[4200,0],[4200,1400],[3200,2200],[900,2200],[0,1500]],
  "margin": 150,
  "items": [
    { "id": "A-箱", "weight": 120, "center": [1200, 800] },
    { "id": "B-桶", "weight": 210, "center": { "x": 2400, "y": 1100 } }
  ]
}
```

页面「载入示例」可直接填入一份可用数据。

## 关键实现

| 文件 | 内容 |
| --- | --- |
| `src/lib/geometry.ts` | 严格凸/逆时针校验、有符号距离、加权重心（溢出时 totalWeight=null）、分辨极限感知的内缩（直接交点构造 + 半平面裁剪兜底）、`analyzeStability` 单一结果源 |
| `src/lib/parse.ts` | 导入数据严格校验（未知字段、范围、件数、整批拒绝） |
| `src/lib/form.ts` | 编辑表单解析，非法即撤销结论；`fmt` 不抹零（科学计数法）、`fmtPair` 成对可区分格式化 |
| `src/components/PlanView.tsx` | 与数值面板共用 `StabilityResult` 的 SVG 俯视图；按可放行状态着色，不可表达量图面告警 |
| `src/components/ResultPanel.tsx` | STABLE / 暂缓放行 / UNSTABLE、最危险边、成对可区分的实际余量与短缺量、溢出缺失反馈 |
| `src/lib/geometry.test.ts` | 凸性/退化/自交、距离符号、加权重心、内缩塌缩、边界稳定性、整批拒绝等用例 |
| `src/lib/acceptance.test.ts` | 极小正余量内缩、边界重心、微小短缺不抹零、大重量溢出、低于分辨极限、导入编辑一致性等验收用例 |
